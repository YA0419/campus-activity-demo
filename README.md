# 校園活動地圖｜教授展示版

這是可放在GitHub Pages的純靜態學生前台，並非即時活動系統。
活動資料為2026/11/19匯出的11筆真實公開活動；日期分類使用Asia/Taipei，隨訪客實際查看時間判斷，不把2026活動永遠凍結為近期。

包含首頁、搜尋、分類與福利篩選、近期／歷史／日期待確認、活動詳情、完整校園地圖、12地點及活動泡泡。
沒有帳號登入、管理後台、資料庫、爬蟲或排程。原系統完整保留；此展示資料不會自動更新。
活動表單與官方連結僅供參考，不代表目前開放報名或尚有名額。

校園地圖由使用者確認取得校方或繪者同意，可用於本次教授展示，保留圖片原署名；這不是通用開放授權聲明。
資管系系學會已明確同意國際生聚餐（11/20）與資窯淨灘（12/12）兩張海報公開展示，本版本包含這兩張無損壓縮海報。其他9筆活動海報的公開使用條件尚未確認，維持「暫無活動海報」佔位。原圖比例、文字及QR Code完整保留；此同意不擴及其他活動圖片。

部署時，請將本資料夾的內容放在GitHub儲存庫根目錄，包含index.html、data、images、CSS、JS、campus-locations.json及.nojekyll。GitHub Pages選main分支、/(root)。本版本沒有建置步驟或額外套件。
